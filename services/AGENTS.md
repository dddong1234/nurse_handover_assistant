# Services Harness

이 디렉터리는 UI에 독립적인 환자 데이터 처리, 변화 검출, 조회와 요약 로직을 담당한다.

## 규칙

- `streamlit` 또는 `app`을 import하지 않는다.
- UI 문자열보다 구조화된 반환값을 우선한다.
- 변화 검출 결과에는 변경 유형, 이전값, 현재값과 근거가 보존되어야 한다.
- deterministic 검출과 LLM 표현 계층을 분리한다.
- 새 동작 또는 버그 수정에는 먼저 실패하는 테스트를 추가한다.
- 저장소 접근이 필요 없는 순수 비교 로직은 I/O와 분리한다.
- Vercel Function 실행을 전제로 요청 간 전역 상태와 로컬 파일 쓰기에 의존하지 않는다.

## 금지

- 실제 환자 데이터 추가
- `.env` 직접 출력 또는 API 키 로깅
- UI 요구에 맞춘 임상 규칙 축소
- 승인 없는 데이터 필드 또는 의미 변경
- 배포 환경의 로컬 JSON 파일을 영속 저장소로 사용하는 구현
