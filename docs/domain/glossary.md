# 간호 인수인계 도메인 용어

## 현재 확정된 용어

### 현재 기록

환자별 최신 JSON 파일이다. 현 MVP의 현재 상태를 나타내지만 실제 EMR의 확정 기록이나 단일 진실 원본을 의미하지 않는다.

### Snapshot

현재 기록을 덮어쓰기 전에 저장한 이전 JSON 사본이다. 현 MVP에서는 비교 기준으로 사용하지만 실제 교대 시작 시점과 동일하지 않을 수 있다.

### 변화 항목

두 기록 사이에서 deterministic 규칙으로 검출한 바이탈, 투약, 진단 또는 메모의 차이다.

### 인수인계 요약

검출된 변화 항목을 간호사가 검토하기 쉽게 정리한 표현이다. 임상 판단이나 원본 기록을 대체하지 않는다.

### 근거

요약 내용이 파생된 원본 필드, 이전값, 현재값과 기록 시점이다.

### Handover Assistant

변화를 찾아 정리하고 원본 확인을 돕는 보조 기능이다. 최종 확인과 전달 책임은 사용자에게 있다.

### Shift Readiness

휴무 복귀 간호사가 이번 근무에 확인할 기록 기반 항목을 실제 인계 순서로 검토하는 작업공간이다. 기존 변화 비교를 대체하지 않고, 그 변화와 operational source를 근거 계층으로 사용한다.

### 사실 상태

검사 `결과 있음`·`예정`, Device `사용 중`·`교체 시점`, 투약 `이번 근무 적용`, 전달 요청 `열림`처럼 원본 구조화 데이터에 기록된 상태다. 정상·비정상, 중증도, 조치 필요성을 새로 판정하지 않는다.

### 확인함

사용자가 항목을 읽고 개인 검토 표시를 남겼다는 뜻이다. 시행 완료, 안전 확인, 인계 완료 또는 다른 간호사의 확인을 뜻하지 않으며 현재 브라우저 탭 세션에만 보관된다.

### 이번 근무 예정

원본에 기록된 scheduled/effective/due 시각이 선택한 근무 구간에 포함된다는 시간 관계다. 시스템이 처방이나 간호 행위를 새로 지시한다는 뜻이 아니다.

### 명시된 전달 요청

`physician_order` 또는 `nursing_note`의 `handoffRequests` 원천에 실제로 기록된 open 요청이다. 활력징후·검사값·일반 메모만으로 보고 필요를 추론하지 않는다.

### 검토 진행

전체 표시 항목 중 현재 review key에서 `확인함`으로 표시한 수다. 임상적 완료율이나 환자 안전 상태가 아니며 항목이 없을 때 `0/0` 완료처럼 표시하지 않는다.

## 실제 도입에서 확정이 필요한 용어

대표 임상 환경이 결정되면 다음 용어의 병동별 의미를 확정한다.

- 교대 구간과 비교 기준 시각
- 중요 변화와 일반 변화
- 기관별 미완료 업무
- 공유 확인 또는 인계 완료 상태
- 보고·에스컬레이션 상태
