# 간호 인수인계 보조 워크플로

## 현재 MVP 흐름

1. 사용자가 환자 기록을 입력하거나 수정한다.
2. 기존 최신본이 있으면 snapshot으로 저장한다.
3. 수정 데이터를 현재 기록으로 저장한다.
4. 인수인계 화면이 최신 snapshot과 현재 기록을 불러온다.
5. deterministic 로직이 바이탈, 투약, 진단과 메모의 차이를 검출한다.
6. UI가 변화 목록과 이전·현재 원본을 함께 표시한다.
7. 질의 화면은 규칙 기반으로 환자와 기록을 검색한다.

## 목표 흐름

1. 사용자가 병동 또는 담당 환자 목록에서 우선 검토 대상을 본다.
2. 시스템이 승인된 인수인계 구간의 구조화된 데이터를 비교한다.
3. 중요한 변화, 일반 변화, 데이터 부족을 구분한다.
4. 요약은 각 변화의 원본 근거로 이동할 수 있다.
5. 간호사는 요약을 검토하고 필요한 항목을 수정 또는 확인한다.
6. AI 문장화가 실패해도 deterministic 변화 목록으로 계속 사용할 수 있다.
7. 사용성·정확성 지표가 포트폴리오 평가 자료로 남는다.

## 아직 인간 결정이 필요한 항목

- 대표 임상 환경: 일반병동, ICU, 응급실 등
- 인수인계 유형: 교대, 전동, 입·퇴원 등
- 인수인계 구조: SBAR 또는 병원별 양식
- 중요도와 보고 기준
- 간호사의 확인·수정·완료 상태가 필요한 범위
