# 실패 기록

실패 기록은 같은 접근을 근거 없이 반복하지 않도록 남긴다.

각 기록에는 시도한 날짜와 목적, 실제 방법, 오류, 근본 원인, 현재 대안, 재시도 조건과 후속 에이전트 지침을 포함한다.

## 기본 `python` 명령으로 로컬 검증 실패

- 날짜: 2026-08-27
- 증상: PowerShell에서 `python`을 찾지 못했고 `py -3.12`에도 설치된 Python이 없었다.
- 원인: 저장소의 `venv`는 Linux 형식이며 현재 Windows 셸에서 직접 사용할 수 없다.
- 대안: Codex 번들 Python의 명시적 경로로 하네스 테스트를 실행한다.
- 재시도 조건: 프로젝트용 Windows 가상환경을 구성하거나 PATH가 명확히 설정된 뒤 기본 명령을 재검증한다.
- 지침: 실행하지 못한 명령을 성공으로 기록하지 말고 실제 사용한 Python 경로를 작업 기록에 남긴다.

## 현재 성능 평가가 정확성 검증을 대체하지 못함

- `benchmark.py`의 manual 비교도 코드로 구현되어 독립적인 임상 정답이 아니다.
- `human_eval.py`의 현재 지표는 변경 개수 일치를 사용해 내용 단위 누락과 오탐을 충분히 측정하지 못한다.
- 이후 비교 엔진 검증에는 사람이 라벨링한 항목별 정답과 중요도별 재현율·정밀도를 사용한다.
