# Sample Dataset

Streamlit MVP 시연용 가상 환자 데이터셋이다.

## 포함 환자

- `P001`: 인후염 환자, 발열 및 혈압 상승, 신규 진단/투약 추가
- `P002`: 폐렴 환자, 산소 요구량 감소와 해열 경과
- `P003`: 심부전 환자, 이뇨제 증량 및 부정맥 진단 추가
- `P004`: 충수절제술 후 환자, 통증 감소와 활동 증가
- `P005`: 당뇨발 궤양 환자, 항생제 추가와 체온 안정화

## 사용 목적

1. `환자 목록` 탭에서 다양한 임상 케이스를 바로 확인
2. `인수인계` 탭에서 이전 snapshot 대비 변화 요약 확인
3. 포트폴리오 시연 시 단일 환자 의존 없이 여러 패턴 재현

## 파일 구조

- 최신 환자 데이터: `data/patients/*.json`
- 이전 snapshot: `data/history/{patient_id}/*.json`

## 주의

모든 데이터는 데모용 가상 데이터이며 실제 환자 정보가 아니다.
