# Tests Harness

이 디렉터리는 사용자에게 보이는 동작과 안전 경계를 검증한다.

## 규칙

- 새 기능과 버그 수정은 실패하는 테스트를 먼저 작성한다.
- 테스트명은 방지하려는 구체적인 결함을 설명한다.
- 기대값은 구현 코드가 아니라 사람이 확인한 리터럴과 fixture에서 도출한다.
- 외부 API를 제외하면 실제 코드를 실행하고 불필요한 mock을 사용하지 않는다.
- OpenAI 통합 테스트와 오프라인 테스트를 구분한다.
- 단순 변경 개수뿐 아니라 변경 내용, 근거, 누락과 오탐을 검증한다.
- 테스트를 실행하지 못하면 원인과 대체 검증을 보고한다.
